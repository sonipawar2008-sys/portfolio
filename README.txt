Dr. P. Soni Pawar - Portfolio website
=====================================
Files
  index.html              the page
  assets/css/style.css    colours, layout and animations
  assets/js/main.js       scroll animations, counters, typing effect, menu
  assets/img/profile.jpg  your photo (replace this file to change the picture,
                          keeping the same name)

To view: double-click index.html (needs internet for Bootstrap and fonts).
To publish free: upload the whole folder to GitHub Pages, Netlify Drop
(drag the folder onto app.netlify.com/drop) or your college web space.
